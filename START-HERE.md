# Abed Al Karim Hijazi Law Office — Refined Edition

This is the elegant, motion-conscious redesign prepared for review. The existing static GitHub Pages architecture, domain configuration (`CNAME`), legal pages, contact details, and English/French/Arabic translation system are retained.

## See the website before publishing

1. Extract the ZIP file.
2. Open `index.html` in a browser. For consistent local-file behavior, optionally serve the folder with `python -m http.server 8000` and visit `http://localhost:8000`.
3. Switch EN / FR / AR, scroll the homepage, inspect the navigation and contact links, and test the site on your phone.

## Publish only after approval

Recommended: create a new Git branch, replace all repository files with the contents **inside** this ZIP (not the ZIP itself), commit to the branch, review, and merge when satisfied. The `CNAME` file must remain at the repository root for your existing domain. If you use GitHub Desktop, this is easier than uploading individual files.

## New design files

- `refined.css` — complete visual direction and motion styling.
- `refined.js` — minimal entrance, scroll and interaction effects; discreet WhatsApp shortcut.
- `refined-translations.js` — English, French and Arabic copy for the new homepage.
- Updated `index.html` and consistent navigation/styles in the remaining HTML pages.

Animations respect the visitor's operating-system **Reduced Motion** preference. No animation frameworks, trackers, or paid runtime dependencies have been introduced.
